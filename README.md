# Тетрис!
Тетрис на C# WinForms. Отличается от классического варианта наличием бомб и квадратиков 1х1.


Реализованы:
* Генерация фигур тетрамино
* Вращение фигур
* Перемещение фигур
* Размещение фигур на игровом поле
* Удаление заполненных рядов игрового поля
* Окончание игры
* Подсчет количества очков
* Показ следующей фигуры


[Скачать последнюю версию (Tetris.exe)](https://github.com/ваш-аккаунт/Tetris-Game/releases/latest)

**Управление в игре:**
* `←` `→` — движение влево/вправо
* `↑` — вращение фигуры (или особое действие)
* `↓` — ускорение падения


Благодаря паттерну, чтобы добавить новую фигуру теперь достаточно добавить фабрику, реализующую интерфейс IPieceProvider и класс фигуры, реализующий интерфейс Tetromino. Первым нововведением стал класс уменьшающейся I, а вторым - бомба.
